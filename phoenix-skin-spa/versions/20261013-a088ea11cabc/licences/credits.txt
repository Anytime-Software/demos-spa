CODE AND EFFECTS
React and React DOM (MIT, Meta Platforms), three.js (MIT, three.js authors), Framer Motion (MIT, Framer B.V.),
Lenis smooth scroll (MIT, darkroom.engineering), Vite (MIT). Simplex noise GLSL by Ashima Arts / Stefan
Gustavson (MIT).
Hero 3D glass drop, desert-light shader and dust were written for this concept. Interaction patterns (masked
text reveal, scroll-linked words, 3D tilt card with glare, sticky stacking cards, horizontal scroll gallery,
magnetic button) follow patterns popularised by Aceternity UI and 21st.dev; the code here is written fresh.
Layout direction continues the retained Aurelle-X editorial base (dark cinematic hero, large serif type).
